## Projets

### SMART_STATION

Système IoT intelligent de surveillance environnementale basé sur ESP32, intégrant plusieurs capteurs, une infrastructure cloud et des fonctions d'analyse.

Technologies principales :

`ESP32` `IoT` `Supabase` `PostgreSQL` `Gemini AI` `DHT11` `BMP280` `MQ-2`

### Distributeur automatique intelligent

Système embarqué automatisé intégrant mesure de poids, programmation horaire, interface utilisateur et commande d'actionneurs.

Technologies principales :

`ESP32` `Arduino` `HX711` `RTC DS3231` `LCD I2C`

### Station météo IoT

Station autonome destinée à mesurer et transmettre des données environnementales avec gestion basse consommation.

Technologies principales :

`ESP32` `BME280` `MQTT` `Wi-Fi` `Li-ion` `Deep Sleep`
